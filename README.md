# Fredrik Almnes — personlig portefølje

Personlig porteføljenettside bygget med Next.js, React, TypeScript og Tailwind CSS.

## Kom i gang

```bash
npm run dev
```

Åpne [http://localhost:3000](http://localhost:3000) for å se siden.

## Struktur

- `src/data/content.ts` — alt tekstinnhold (navn, prosjekter, erfaring, ferdigheter, kontaktinfo). Rediger denne filen for å oppdatere siden.
- `src/components/` — seksjonene på siden (Hero, Nå, Prosjekter, Erfaring, Ferdigheter, Kontakt).
- `src/app/globals.css` — farger, fonter og grid-bakgrunn.

## Ting som gjenstår

- Bytt ut placeholder-prosjektkortet ("Under arbeid") når neste prosjekt er klart.

## Deploy

Enkleste måte å publisere siden på er [Vercel](https://vercel.com/new).
